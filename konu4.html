Konu 4 — Sürekli Rassal Değişkenler

Sonsuz sayıda değer alabilen değişkenler, PDF, CDF ve integral hesabı.

4.1 Sürekli Rassal Değişken

Belirli bir aralıkta sonsuz sayıda değer alabilen değişkenlerdir.

Yazılım örnekleri:

  • API yanıt süresi: X ∈ [0, ∞) ms
  • Sunucu CPU kullanımı: X ∈ [0, 100] %
  • Ağ gecikme süresi: X ∈ [0, ∞) ms

Sürekli değişkende tek bir noktanın olasılığı sıfırdır: \(P(X = a) = 0\)

4.2 Olasılık Yoğunluk Fonksiyonu (PDF)

\(f(x)\) fonksiyonu şu koşulları sağlamalı:

\[ f(x) \geq 0 \qquad \text{ve} \qquad \int_{-\infty}^{\infty} f(x)\,dx = 1 \]

Aralık olasılığı:

\[ P(a \leq X \leq b) = \int_a^b f(x)\,dx \]

4.3 Kümülatif Dağılım Fonksiyonu (CDF)

\[ F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\,dt \]

CDF özellikleri:

  • \(0 \leq F(x) \leq 1\) her x için
  • Artan fonksiyon: \(x_1 < x_2 \Rightarrow F(x_1) \leq F(x_2)\)
  • \(\lim_{x \to -\infty} F(x) = 0\) ve \(\lim_{x \to +\infty} F(x) = 1\)
  • Aralık: \(P(a \leq X \leq b) = F(b) - F(a)\)

4.4 Beklenen Değer

\[ E(X) = \int_{-\infty}^{\infty} x \cdot f(x)\,dx \]

4.5 Varyans

\[ V(X) = E(X^2) - [E(X)]^2 \qquad \text{burada} \quad E(X^2) = \int_{-\infty}^{\infty} x^2 f(x)\,dx \]

4.6 Medyan

\[ F(m) = P(X \leq m) = 0{,}5 \]

Çözümlü Sorular

Soru 1 — c Sabiti ve Alan Hesabı

Bir API'nin yanıt süresi (saniye) için \(f(x) = cx^2,\; 0 \leq x \leq 2\) ve diğer yerlerde 0.

(a) c = ?    (b) P(0,5 ≤ X ≤ 1,5) = ?

Adım 1 — c'yi bul (∫f(x)dx = 1) \[\int_0^2 cx^2\,dx = c\left[\frac{x^3}{3}\right]_0^2 = c \cdot \frac{8}{3} = 1 \Rightarrow c = \frac{3}{8}\]
Adım 2 — P(0,5 ≤ X ≤ 1,5) \[P(0{,}5 \leq X \leq 1{,}5) = \int_{0{,}5}^{1{,}5} \frac{3}{8}x^2\,dx = \frac{3}{8}\left[\frac{x^3}{3}\right]_{0{,}5}^{1{,}5}\] \[= \frac{1}{8}\left[(1{,}5)^3 - (0{,}5)^3\right] = \frac{1}{8}[3{,}375 - 0{,}125] = \frac{3{,}25}{8} \approx 0{,}406\]
Sonuç c = 3/8  |  P(0,5 ≤ X ≤ 1,5) ≈ 0,406
Soru 2 — E(X), V(X) ve Medyan

Bir sunucunun işlem süresi için \(f(x) = 3x^2,\; 0 \leq x \leq 1\).

(a) E(X) = ?    (b) V(X) = ?    (c) Medyan = ?

Adım 1 — E(X) \[E(X) = \int_0^1 x \cdot 3x^2\,dx = 3\int_0^1 x^3\,dx = 3\left[\frac{x^4}{4}\right]_0^1 = \frac{3}{4} = 0{,}75\]
Adım 2 — E(X²) \[E(X^2) = \int_0^1 x^2 \cdot 3x^2\,dx = 3\int_0^1 x^4\,dx = 3\left[\frac{x^5}{5}\right]_0^1 = \frac{3}{5} = 0{,}6\]
Adım 3 — V(X) \[V(X) = 0{,}6 - (0{,}75)^2 = 0{,}6 - 0{,}5625 = 0{,}0375\]
Adım 4 — Medyan (F(m) = 0,5) \[F(m) = \int_0^m 3x^2\,dx = [x^3]_0^m = m^3 = 0{,}5 \Rightarrow m = \sqrt[3]{0{,}5} \approx 0{,}794\] ✔ E(X)=0,75 | V(X)=0,0375 | Medyan≈0,794

Pratik Sorular

Soru 1. \(f(x) = kx,\; 0 \leq x \leq 2\). (a) k'yı bul. (b) E(X)'i hesapla. (c) P(1 ≤ X ≤ 2) nedir?

(a) \(\int_0^2 kx\,dx = k\cdot 2 = 1 \Rightarrow k = \frac{1}{2}\)
(b) \(E(X) = \int_0^2 x \cdot \frac{x}{2}\,dx = \frac{1}{2}\int_0^2 x^2\,dx = \frac{1}{2} \cdot \frac{8}{3} = \frac{4}{3} \approx 1{,}33\)
(c) \(\int_1^2 \frac{x}{2}\,dx = \frac{1}{2}\left[\frac{x^2}{2}\right]_1^2 = \frac{1}{4}(4-1) = \frac{3}{4} = 0{,}75\)

Soru 2. \(f(x) = 2x,\; 0 \leq x \leq 1\). P(0,3 ≤ X ≤ 0,7) ve Medyanı bul.

\(P(0{,}3 \leq X \leq 0{,}7) = \int_{0{,}3}^{0{,}7} 2x\,dx = [x^2]_{0{,}3}^{0{,}7} = 0{,}49 - 0{,}09 = 0{,}40\)
Medyan: \(F(m) = m^2 = 0{,}5 \Rightarrow m = \sqrt{0{,}5} \approx 0{,}707\)

Soru 3. \(f(x) = 4x^3,\; 0 \leq x \leq 1\). E(X), V(X) ve CDF F(x)'i bul.

\(E(X) = \int_0^1 x \cdot 4x^3\,dx = 4\int_0^1 x^4\,dx = 4/5 = 0{,}8\)
\(E(X^2) = \int_0^1 x^2 \cdot 4x^3\,dx = 4\int_0^1 x^5\,dx = 4/6 = 2/3\)
\(V(X) = 2/3 - (4/5)^2 = 2/3 - 16/25 = 50/75 - 48/75 = 2/75 \approx 0{,}027\)
\(F(x) = \int_0^x 4t^3\,dt = x^4\)
